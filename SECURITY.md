# Security Policy

## Supported versions

Only the latest release tag receives fixes. Consumers pinned to an older
tag should upgrade per `MIGRATION.md`.

## Reporting a vulnerability

Report privately through GitHub: **Security → Report a vulnerability** on
this repository. Please do not open a public issue for a suspected
vulnerability.

Relevant scope includes the validator and bootstrap scripts under
`scripts/`, the container templates under `templates/codegraph/`, and any
guidance that would lead a consumer to weaken an isolation or secret-
handling control (`core/SECURITY_CONTROLS.md`).

You should receive an acknowledgement within 7 days.
