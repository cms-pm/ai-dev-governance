# CodeGraph Consumer Contract

This document is generated by `ai-dev-governance` bootstrap/retrofit so every
consumer makes an explicit CodeGraph (CG) decision after adopting ADG v1.1.0 or
newer.

## Current Declaration

- Status: not declared by default.
- Non-CG consumers remain compliant when `governance.yaml` omits both
  `evidence.codegraphIndexFreshnessURI` and
  `evidence.codegraphImageDigestURI`.
- If a consumer declares either CodeGraph evidence URI, it is a CG-declared
  consumer and must satisfy the activation contract below before using CG
  output as release or acceptance evidence.

## Awareness Contract

All ADG v1.1.0+ consumers should know the CG contract even when they do not
enable it:

- Astaire remains the port-of-first-resort for governance artifacts.
- CodeGraph is optional Tier-2 source-code intelligence for declared product
  source scopes.
- Graphify is not an active ADG integration surface.
- Native source tools remain valid for non-CG consumers.
- In CG-declared consumers, agents must query CodeGraph before token-heavy
  native source spidering for symbol discovery, seams, caller/callee paths,
  impact analysis, and refactor context.

## Activation Contract

To enable CodeGraph, the consumer must provide:

- `governance.yaml` evidence URIs:
  - `codegraphIndexFreshnessURI`
  - `codegraphImageDigestURI`
- `.mcp.json` with `mcpServers.codegraph.command` invoking the
  `codegraph-mcp` wrapper, not raw `npx` or a mutable host install.
- `.codegraphignore` excluding the ADG submodule path and other out-of-scope
  generated, vendored, or secret-bearing paths.
- `.codegraph/image.digest` containing an immutable SHA-256 digest.
- `.codegraph/evidence/sbom.spdx.json` for runtime/image provenance.
- A fresh `.codegraph/` index for the declared source path scope.

The ADG-published MCP fragment invokes the pinned CodeGraph image with:

```json
{
  "args": ["serve", "--mcp", "--no-watch"]
}
```

There is no npm fallback in the ADG CG contract. Consumers must use the
strict Docker/container wrapper path or leave CG undeclared.

## Required Validation

For CG-declared consumers, run this before release or before citing CG as
evidence:

```bash
.governance/ai-dev-governance/scripts/validate_codegraph_wiring.sh --root .
```

The release is blocked if the validator fails or if either CG evidence URI is
present without matching local evidence artifacts.

## Provider Wiring

- Claude: use `.governance/ai-dev-governance/adapters/providers/claude/CODEGRAPH.md`
  and merge the `templates/codegraph/settings.json.fragment` and
  `templates/codegraph/CLAUDE.md.fragment` guidance.
- Codex: use `.governance/ai-dev-governance/adapters/providers/codex/CODEGRAPH.md`
  and adapt `templates/codegraph/CLAUDE.md.fragment` into `AGENTS.md`.
- Both providers: use `.governance/ai-dev-governance/templates/codegraph/.mcp.json.fragment`
  as the MCP server contract and keep the wrapper invocation intact.

## Upgrade Decision

When upgrading from a pre-v1.1.0 ADG release:

1. Decide whether the project declares CG now.
2. If not declaring CG, keep both CG evidence URIs absent and retain this file
   as the decision record.
3. If declaring CG, apply the activation contract and run the validator above.
4. Record any stale/unavailable CG fallback before broad native source
   discovery in implementation notes.
